# 🌐 Google Translator using Python & Tkinter

This project is a **GUI-based language translator** developed using **Python**, **Tkinter**, and the **googletrans** library.  
It enables users to translate text from one language to another by selecting source and destination languages from a dropdown list.

---

## 🚀 Features

- User-friendly desktop GUI
- Supports multiple languages
- Uses Google Translate via `googletrans`
- Source and destination language selection
- Real-time text translation
- Clean and simple interface

---

## 🛠️ Technologies Used

- Python
- Tkinter (GUI)
- ttk (Themed Widgets)
- googletrans library

---
   
🖥️ How It Works
1.Enter text in the Source Text box

2.Select the source language

3.Select the destination language

4.Click Translate

5.Translated text appears in the Destination Text box
